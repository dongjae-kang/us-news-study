# 🗽 미국 뉴스 공부 노트

매일 미국에서 크게 다뤄진 뉴스를 한국어로 읽고, **왜 오늘 뉴스가 됐는지 · 무엇을 왜 뺐는지 · 영어 표현**까지 함께 쌓는 개인 학습 노트.
원본은 [PRISM](https://prism-news.org/en) 의 그날 카드입니다.

- 사이트: https://dongjae-kang.github.io/us-news-study/
- 원고: `days/<날짜>.md` (하루 한 장) → `build.py` 가 날짜별 · 이야기 줄기 · 용어집 · 영어 표현 페이지를 만든다
- 쓰는 법: [WRITING-GUIDE.md](WRITING-GUIDE.md) · 검사: `check_day.py`
- 읽으며 남기는 메모: `notes.html` — 카드마다 👍/👎 와 한 줄, 그날 묶음에 한 줄, 뺀 뉴스에 "넣었어야" 표시. 메모는 읽는 사람의 브라우저에만 저장되고 어디로도 전송되지 않는다(복사·파일로 저장으로 꺼낸다). 날짜별 페이지의 메모 칸은 그 브라우저에서 `notes.html` 을 한 번 연 뒤에만 보인다.

📄 = 뉴스 자료에서 온 내용 · 🧭 = 이해를 돕는 배경 설명(제도·개념)
